# Grocery Demand Forecasting using Scikit-learn

This project forecasts grocery product demand using historical sales, price, promotions, day of week, and holiday information.

## Run
1. Install dependencies:
   pip install -r requirements.txt
2. Train the model:
   python train_model.py
3. Forecast demand for a new day:
   python predict.py

The included dataset is synthetic and stored in `data/grocery_sales.csv`.
